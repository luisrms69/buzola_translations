# Buzola Translations

Catálogo de traducciones locales en español (México) que se superpone a las apps del
ecosistema Frappe/ERPNext sin modificarlas.

- **Manual de usuario:** cómo instalar y activar el catálogo local.
- **Documentación técnica:** mecanismo de sobrescritura, flujo de extracción y compilación.
- **ADR:** decisiones arquitectónicas permanentes.

El gobierno del proyecto (propósito, alcance, exclusiones, criterios de terminación) vive en
el documento rector: `frappe-infrastructure/projects/buzola_translations/plan-rector.md`.
